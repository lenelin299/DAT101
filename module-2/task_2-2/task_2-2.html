1. 1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Constants should be used for values that doesnt change after they are set (Const is a promise to JS that this value will never change). Fixed factors such as days in a week, months in a year and hours in a day. Also calculations that are done once. Variables should be used for values that change, such as age, todays date etc. Both are boxes, but const has a sealed lid and let has a open lid. No, they can not all be constants because the const does not allow a new value. Some values must change, like remainder, while the program runs.

    3. JS followes the mathematics order of operations; multilpy, divide, addition and subtraction. The parentheses forces JS to calculate the values inside first.

  3. 3. How do we limit floating-point numbers to a given number of decimals?

    4. By using toFixed(n), which rounds the number to n decimals and returns it as a string. If we need to keep the value as a number, we use Math.round(number * 100) / 100, where 100 gives two decimals.

  5. 5. What do comparison operators return, and how can we check if they are FALSE or TRUE?
